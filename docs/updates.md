# Обновления

## Переход со старых 8.4.x на 1.0.0

Публичная нумерация начата заново. Старый установщик 8.x считает 1.0.0 более низкой версией.

Сделай резервную копию папки. Распакуй новый ZIP отдельно и перенеси **только `run.bat`, `update.bat` и `updater.py`** в свою старую папку. Запусти `update.bat` или `py -3 updater.py` (либо `python updater.py`). Новый обновлятор понимает переход 8.x → 1.x и сохраняет личные данные. После установки перезапусти программу. В серии 1.x обновления выполняются обычным меню u.

## Установка новой версии

Из меню выбери **u**. Программа закрывает свои соединения перед запуском обновления. Подтверди установку и перезапусти `run.bat` / `run.sh`.

Или запусти:

```bash
python updater.py --check  # только проверить
python updater.py         # спросить перед установкой
```

На Windows есть `update.bat`, на Linux/macOS — `sh update.sh`.

Обновление не ставится молча и не проверяется в фоне при каждом запуске. Сначала скачивается ZIP, проверяется SHA-256 и состав файлов, затем создаётся резервная копия заменяемого кода. При обычной ошибке записи старые файлы восстанавливаются.

Сохраняются `.env`, база, Telegram-сессии, `settings.json`, прогресс, кэш, логи, `ready.txt` и свои словари. Встроенные `words_en.txt` / `words_ru.txt` обновляются вместе с программой. Свои слова храни в `data/custom_words.txt`.

**Закрой другие копии программы.** Не запускай обновление параллельно с поиском в другом окне. Копии кода находятся в `data/backups/`; старые копии можно удалить вручную после проверки новой версии.

## Если GitHub недоступен

Скачай ZIP на странице Releases через доступное соединение. Прокси `PROXY` в `.env` предназначен для Telegram и не применяется к обновлению GitHub. Для ручной установки сначала сделай копию текущей папки; перенеси код из ZIP в существующую папку без удаления `.env` и `data/`.

## Ручное восстановление

Закрой программу. Выбери нужную папку `data/backups/`. Скопируй из неё старые файлы поверх проекта, сохранив пути. `restore.json` указывает, какие файлы были до обновления (`true`), а какие добавились (`false`): добавленные файлы при полном откате нужно удалить. Перезапусти программу; окружение переустановит зависимости при изменении requirements.txt.

SHA-256 выявляет повреждение файла, но не заменяет подпись автора. Доверяй только официальному репозиторию.
