# Первый запуск

1. Установи Python 3.10+ с python.org. На Windows включи **Add Python to PATH**.
2. Скачай ZIP из последнего GitHub Release и распакуй его в обычную папку.
3. Windows: запусти `run.bat`. Linux/macOS: открой терминал в папке и выполни `sh run.sh`.
4. Первый запуск создаст `.venv` и установит зависимости. Нужен интернет.
5. Для Telegram API получи свои API_ID / API_HASH на https://my.telegram.org, затем выбери настройку API в программе или выполни `python cli.py setup` внутри окружения.

Другой вариант: скопируй `.env.example` в `.env` и укажи ключи вручную. Не публикуй `.env`.

## Аккаунт Telegram

Меню **9 → a**: добавь свой аккаунт. Номер, код и 2FA вводятся локально. Сессии сохраняются в `data/sessions/` и не входят в GitHub или релиз.

## Проблемы подключения

- `Server closed the connection`: проверь интернет, VPN или прокси.
- `FloodWait`: Telegram ограничил запросы. Дождись окончания паузы; не считай жёлтые результаты свободными.
- Жёлтые 🟡 юзы: требуется перепроверка; меню **6**.
- Linux: если venv не создаётся, установи пакет `python3-venv` средствами своего дистрибутива.
- Диагностика: меню **d**, `python doctor.py` или `python bootstrap.py doctor`. Для проверки установленных зависимостей запускай doctor Python-интерпретатором из `.venv`.

## Прокси Telegram

В `.env`:

```dotenv
PROXY=socks5://127.0.0.1:1080
# либо PROXY=mtproxy://SECRET@host:port
```

Это настройки Telegram-соединения, не универсальный VPN для сайтов и GitHub.

## Если проверено 0

В серии 1.0.2 панель показывает текущее состояние. **Отбор кандидатов** означает генерацию и фильтрацию до сетевых проверок; высокий порог S+ может отсеять почти всё. **Ожидание ответов сайтов / API** означает сетевую пачку, возможны таймауты или FloodWait. Таймер должен продолжать обновляться.

`p5` распознаётся как `5p`. В диалоге переключения 1 меняет только пресет, 2 — только уровень, 3 — оба. Если нужен менее строгий поиск, выбери A или B явно; программа не гарантирует доступность или цену имён.
