## Username Hunter 1.0.0

Первый релиз новой публичной серии. Нумерация начинается с **1.0.0**, следующие исправления — **1.0.1**, **1.0.2**.

- Исправленные Windows-запускатели: ASCII, CRLF, без многострочного if/else.
- Поиск, скоринг, Fragment, слежка, база и аккаунты сохранены.
- Обновления с SHA-256, резервной копией кода и сохранением личных данных.
- Поддержка перехода с известных старых версий 8.x в новом обновляторе.
- Офлайн-тесты на Windows, Linux и macOS; BAT-файлы выполняются через настоящий CMD с безопасными заглушками.

### Первый запуск

Python 3.10+. Распакуй ZIP → `run.bat` на Windows или `sh run.sh` на Linux/macOS.

### Если установлена 8.4.x

1. Сделай резервную копию своей папки программы.
2. Распакуй новый ZIP отдельно.
3. Замени в старой папке **только `run.bat`, `update.bat` и `updater.py`** файлами из нового ZIP.
4. Запусти `update.bat` или выполни `py -3 updater.py` / `python updater.py` в папке программы. Подтверди переход на 1.0.0.
5. После обновления запусти `run.bat` заново.

Старый обновлятор 8.x считает 1.0.0 более низкой версией, поэтому его нужно заменить один раз. `.env`, база, настройки и сессии не заменяются автоматическим обновлением. В новых версиях 1.x достаточно меню **u**.

Старые релизы 8.x сохранены как история, но не являются последней публичной серией. Реальный Telegram-аккаунт в тестах не использовался.
