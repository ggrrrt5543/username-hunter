## GitHub Edition — 8.4.0

- Удобный запуск через отдельное окружение `.venv`: зависимости не ставятся в системный Python и не устанавливаются заново при каждом запуске.
- Меню `u` и команда `update`: проверка стабильной версии, SHA-256, резервная копия кода и откат при ошибке записи.
- Личные данные (`.env`, база, настройки, Telegram-сессии, прогресс, свои словари) не заменяются обновлением.
- Меню `d`, команда `doctor`, флаг `--version`.
- Автосборка ZIP и публикация релизов после офлайн-тестов на Windows, Linux и macOS (Python 3.10 / 3.13).
- Исправлен русский вывод на Windows (UTF-8 вместо системной cp1252).
- Новый README, баннер, документация, шаблон безопасного сообщения об ошибке.

**Требования:** Python 3.10+, интернет для первой установки зависимостей.

**Скачать:** ZIP из Assets ниже. Распаковать → `run.bat` на Windows или `sh run.sh` на Linux/macOS.

**Важно:** тесты не используют реальный Telegram-аккаунт и не подтверждают работу Telegram API. Проверка имени не резервирует его. Цены Fragment — ориентир, не гарантия продажи.
