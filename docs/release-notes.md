## 8.4.1 — исправление запуска Windows

- Переписаны `run.bat` и `update.bat`: ASCII, Windows-переносы CRLF и переходы по меткам вместо многострочного if/else.
- Сборка ZIP принудительно сохраняет правильные переносы `.bat` независимо от ОС сборки.
- Добавлены проверки формата и запуск обоих `.bat` через настоящий CMD в Windows CI (с безопасными заглушками вместо приложения).

**Если 8.4.0 не запускается:** скачай новый ZIP, сделай копию текущей папки и замени только `run.bat` и `update.bat`. Либо открой CMD в папке программы и выполни `py -3 updater.py` (или `python updater.py`), чтобы обновить весь код до 8.4.1.

Личные данные не входят в релиз и не заменяются автоматическим обновлением. После обновления перезапусти программу. Нужен Python 3.10+.
