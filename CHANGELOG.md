# Changelog

## 1.0.2 — отзывчивый поиск и выбор уровня

- `p5/p6/p7` распознаются как `5p/6p/7p`; `d5/d6` — как `5d/6d`.
- Сниженный уровень сохраняется даже при неподходящих фильтрах: следующие нажатия 2 переходят 95 → 85 → 75, а не повторяют 85. История пресетов больше не дублируется.
- Генерация и сортировка кандидатов уступают управление asyncio. В mix дорогой брендовый генератор не блокирует словари и другие источники.
- Небольшая готовая пачка уходит на проверку без ожидания её полного заполнения.
- Живой процент перебора обновляется внутри куска; дисковая точка продолжения сохраняется только после обработки всего куска.
- Добавлены отдельные счётчики оценённых кандидатов, низкого скора, фильтров и пропусков по кэшу. Пустая пачка теперь объясняет причины.
- Живая панель обновляет время независимо от результатов и показывает этап: отбор кандидатов либо ожидание сайтов/API.
- Добавлены тесты сохранения уровня, алиасов, справедливого mix, контрольных точек полного перебора и работы других asyncio-задач.

## 1.0.1 — исправление паузы перед началом поиска

- Список находок создаётся до проверки пресета и диалога смены настроек. Устранён `NameError: found` при неподходящем исходном пресете.
- Уведомление Telegram и окно выбора корректно показывают 0 находок до первой проверки.
- Добавлены три офлайн-регрессии: остановка поиска, уведомление о начальной паузе, переход на другой пресет с продолжением проверки.

## 1.0.0 — первый релиз новой публичной серии

- По решению владельца нумерация начинается с 1.0.0. Следующие исправления — 1.0.1, 1.0.2; новые совместимые возможности — 1.1.0.
- Сохранены исправленные ASCII/CRLF Windows-запускатели и тесты настоящего CMD из 8.4.2.
- Новый обновлятор поддерживает переход с известных старых 8.x на серию 1.x и не возвращает 1.x к старым релизам.
- Для первого перехода с 8.x нужно заменить `updater.py` новым вручную: старый установщик не понимает сброс нумерации. После перехода обновления работают через меню u.

## 8.4.2 — совместимость обновления с 8.4.0

- `.gitattributes` остаётся в Git, но не входит в ZIP: установщик 8.4.0 не принимает этот служебный файл.
- Сохранены все исправления Windows-запуска из 8.4.1.

## 8.4.1 — Windows launcher hotfix

- Windows-запускатели используют CRLF и ASCII, без кириллицы и многострочных блоков `if/else`.
- ZIP-сборка принудительно нормализует `.bat` в CRLF; `.gitattributes` сохраняет правильные переносы при checkout.
- Добавлены проверки содержимого запускателей и реального исполнения через CMD в Windows CI.

## 8.4.0 — GitHub Edition

- GitHub Releases: готовый ZIP, SHA256SUMS и автоматическая публикация новой версии.
- Проверка и установка обновлений с подтверждением; резервная копия кода и откат при ошибке записи.
- `.env`, SQLite, сессии, настройки, прогресс и пользовательский словарь не затрагиваются обновлением.
- Меню `u` (обновление), `d` (диагностика), команды `update`, `doctor`, флаг `--version`.
- Запуск через `.venv`; зависимости переустанавливаются при изменении requirements.txt.
- UTF-8 для русского текста на Windows, в том числе при перенаправлении вывода.
- Офлайн-тесты, кроссплатформенный CI, документация и оформление GitHub.
