# Changelog

## 8.4.0 — GitHub Edition

- GitHub Releases: готовый ZIP, SHA256SUMS и автоматическая публикация новой версии.
- Проверка и установка обновлений с подтверждением; резервная копия кода и откат при ошибке записи.
- `.env`, SQLite, сессии, настройки, прогресс и пользовательский словарь не затрагиваются обновлением.
- Меню `u` (обновление), `d` (диагностика), команды `update`, `doctor`, флаг `--version`.
- Запуск через `.venv`; зависимости переустанавливаются при изменении requirements.txt.
- UTF-8 для русского текста на Windows, в том числе при перенаправлении вывода.
- Офлайн-тесты, кроссплатформенный CI, документация и оформление GitHub.

## 8.3.0 — импорт исходного проекта

Поиск, генераторы и словари, Fragment, скоринг, база, аккаунты, слежка, уведомления и сохранение прогресса. Исходная версия предоставлена владельцем проекта.
